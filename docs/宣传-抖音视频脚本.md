# 抖音宣传片脚本：课堂笔记 App（60 秒）

> 用途：发抖音介绍 classnote。整份内容可以直接粘进 DSH「自媒体工作台」的灵感卡，让它一键生成脚本 / 封面 / 六格分镜；下面的成稿是按抖音节奏手写的版本，可以直接照念。

## 一、先定三件事

| 项 | 选择 | 理由 |
|---|---|---|
| 目标人群 | 大学生（尤其要记大量板书、还要学英语的） | 痛点最具体，转化路径短 |
| 视频形态 | 手机录屏 + 少量实拍 + 口播 | 工具类视频，真实感 > 精致感 |
| 核心卖点 | **不用手抄，录完就有能复习的笔记** | 一句话能说清，且和同类「录音转文字」区分开 |

**不要碰的**：不能说「考试神器」「保过」「提分」，也不能出现真实课堂里老师同学的声音——既违反平台规则，也违反 App 自己的免责声明。

## 二、60 秒口播逐字稿

> 语速按 4.5 字/秒写，约 270 字。念慢了就删括号里的。

**0–3 秒｜钩子（画面：教室后排，手机立在桌上）**

> 上课老师讲得太快，笔记永远记不完？
> （停半秒）我现在上课，只带手机。

**3–12 秒｜痛点（画面：翻笔记本、快进的录音条）**

> 以前我也手抄，抄完发现重点全漏了；想复习，两小时的录音又听不完。
> 后来我把整节课录下来，让 AI 整理。

**12–30 秒｜演示（画面：录屏——点录音 → 实时转写往上滚 → 点「一键处理」）**

> 打开这个 App，点录音，它就一边录一边转成文字。
> 下课点一下「一键处理」，它会自己走完：先按这门课的教材术语纠错，
> 再生成一份九段式笔记——知识点、例题步骤、老师强调的考点，都在里面。

**30–42 秒｜结果（画面：结果页滚动、思维导图缩放）**

> 还会顺手生成思维导图，期末顺着图复习，比翻书快。
> 上英语课更明显：录完直接给你逐句中文对照，点一句就跳回原文那句。

**42–52 秒｜差异点（画面：设置页/成本字幕）**

> 数据全在自己手机里，模型 Key 自己填，不经过任何人的服务器。
> 一节课 40 分钟，成本大概一毛钱。

**52–60 秒｜收尾（画面：GitHub 页面 + APK 安装）**

> 代码开源，安装包在 GitHub 的 Release 里，搜 classnote 就能找到。
> （字幕）先看免责声明：录课前，记得征得老师同意。

## 三、六格分镜

| 镜 | 画面 | 时长 | 字幕/旁白 | 拍摄要点 |
|---|---|---|---|---|
| 1 | 教室后排视角，手机立在桌上，屏幕暗着 | 3s | 上课记笔记，永远记不完？ | 不要拍到人脸和黑板上的真实课程名 |
| 2 | 手机屏幕特写：录音波形 + 转写文字实时往上滚 | 6s | 一边录，一边变成文字 | 录屏；用自己念的一段话做演示音源 |
| 3 | 手指点「一键处理」，转圈 | 3s | 下课点一下 | 录屏；等待画面别剪太快，让观众看懂在跑 |
| 4 | 结果页：九段式笔记快速滚动 | 8s | 知识点 / 例题 / 考点 | 录屏；滚动速度放慢一点 |
| 5 | 思维导图双指缩放 | 5s | 还能生成思维导图 | 录屏；从主图缩到子节点 |
| 6 | 英语课对照界面 + 结尾字幕「GitHub: classnote」 | 8s | 逐句中文对照 / 一节课一毛钱 | 录屏；结尾停 2 秒给二维码或搜索词 |

## 四、标题与文案

**标题候选（选一个，别都堆上）**

1. 上课不记笔记，我靠它复习
2. 把一节课录下来，AI 整理成能复习的笔记
3. 英语课救星：录完自动逐句中文对照

**正文（发布时贴）**

> 自己写的一个小工具，解决「上课记不完、录音听不完」。
> 录音 → 转写 → 按教材术语纠错 → 九段式笔记 + 思维导图，英语课还能逐句对照。
> 数据在本机，Key 自己填，一节课成本一毛左右。开源，安装包在 GitHub Release。
> 提醒：录课前先征得老师同意，AI 生成的内容要自己核对。

**话题**

```
#大学生 #学习工具 #AI工具 #课堂笔记 #效率工具 #英语学习 #开源
```

**封面文案（三选一）**

- 主：上课不用记笔记　副：录完就有复习资料
- 主：两小时的课　副：压成一页能复习的笔记
- 主：英语课听不懂？　副：录完给你逐句中文

## 五、你要录的四段素材

1. 录音页：点录音 → 说 15 秒话 → 停止（录屏）
2. 一键处理：点按钮 → 等它跑完（录屏，可 2 倍速）
3. 结果页：详细笔记滚动 + 思维导图缩放（录屏）
4. 英语课：对照面板点句子回原文（录屏）

配音用你自己的声音就行——工具类视频，真人念比 AI 配音更容易被推。

## 六、合规底线

- 视频里**不要出现真实课堂录音**：老师、同学的声音都属于他人，未经同意不能公开传播；
- 演示用自己念的一段话，或干脆用空白/音乐；
- 不承诺分数、不暗示作弊用途；
- 平台若要求标注 AI 生成内容（封面/配图是 AI 画的），按平台规则标注。
