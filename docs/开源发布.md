# 开源到 GitHub

仓库本身已经准备好开源：README、MIT LICENSE、`.gitignore`、图标源图、构建文档都齐了，
**唯一没做的是推送到 GitHub**——这台机器到 `github.com` 的网络不通（DNS 能解析，HTTPS 连不上），
也没有任何 GitHub 凭据（没有 `gh`、没有 SSH key、没有 credential helper）。

所以下面是你在能上网的机器上要执行的三步。

## 1. 先确认没有敏感信息

已经查过：

- 代码里没有硬编码 Key（`settings_page.dart` 里的 `sk-xxxx` 只是输入框占位提示）
- 全部 git 历史里没有 `sk-` 开头的长字符串
- `build/`、`.dart_tool/`、`ios/Pods/` 都在 `.gitignore` 里

推送前还是建议你自己再扫一眼：

```bash
git log -p --all | grep -E "sk-[A-Za-z0-9]{20,}" || echo "clean"
```

## 2. 在 GitHub 建仓库

网页方式：New repository → 名字 `classnote` → Public → **不要**勾选初始化 README / .gitignore / LICENSE
（仓库里已经有了，勾了会产生一次冲突合并）。

或者装 GitHub CLI 后一条命令：

```bash
gh auth login
gh repo create classnote --public --source=. --remote=origin --push
```

## 3. 推送

```bash
cd E:/Downloads/classnote
git branch -M main
git remote add origin https://github.com/<你的用户名>/classnote.git
git push -u origin main
```

用 SSH 的话把地址换成 `git@github.com:<用户名>/classnote.git`，并先配好 `~/.ssh/id_ed25519`。

### 如果 HTTPS 连不上 github.com（本机就是这种情况）

这台机器 `github.com:443` 不通，但 `ssh.github.com:443` 通。把 SSH 连接改走 443 即可：

```bash
# ~/.ssh/config
Host github.com
  HostName ssh.github.com
  Port 443
  User git
  IdentityFile %d/.ssh/id_ed25519
```

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N "" -C "classnote@windows"
cat ~/.ssh/id_ed25519.pub    # 把公钥加到 GitHub → Settings → SSH and GPG keys
git remote add origin git@github.com:<用户名>/classnote.git
git push -u origin main
```

注意：**浏览器里登录 GitHub ≠ 命令行有权限**。git 需要自己的凭据（SSH key 或 PAT），
浏览器会话不会被 git 复用。

## 4. 推完可以顺手做的

- 仓库 **About** 里填一句话简介和 topics：`flutter` `dart` `speech-to-text` `llm` `notes`
- 打开 Issues（默认就开）
- 把 `README.md` 顶部的图标路径确认能显示（`assets/branding/app_icon_512.png` 已提交）
- 打一个 tag：`git tag v1.1.0 && git push origin v1.1.0`
- 想发 Release 的话，把 `E:\Downloads\classnote-release.apk` 作为附件传上去（APK 不在仓库里，避免每次改代码都让仓库体积变大）

## 5. 别人 clone 之后

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

需要自己在 App「设置」里填两个 Key 才能用 AI 功能（DeepSeek + 硅基流动），仓库里不带任何 Key。
