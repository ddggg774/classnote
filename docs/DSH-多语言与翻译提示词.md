> **怎么用**：新开一个 DSH 会话，从 `### 你是谁` 开始全选到文档末尾，整段发过去。
> 「一、背景」是给你看的，不用复制。

## 一、背景（给人看）

现在这个 App 是纯中文课堂的：转写出来是中文，纠错按同音字/拼音改，总结按九段式写中文，术语表按中文课程生成。到了外语课，这套东西会同时坏掉三处——

1. **纠错会把外语改坏。** 纠错提示词是照着「同音字、平翘舌、拼音」写的，遇到英文/日文，模型很可能"顺手翻译"或者把词改成中文，比不改更糟。
2. **总结读不懂。** 九段式提示词假定输入是中文，输出也要求中文，外语课的笔记会变成机翻味的转述。
3. **学生真正需要的是对照。** 外语课的价值不在"翻译成中文"，而在**原文 + 译文逐句对照**——回听时能对上原话，复习时能核对术语。

目标：给外语课一条完整的链路——

```
录音 → 外语转写（原文完整保留）→ 语言适配的纠错 → 逐句翻译（原文/译文对照）
     → 中文总结（术语首次出现带中文释义）→ 检索与 Wiki 同时认两种语言
```

**本版先只做英语**，而且做成**独立入口**（首页「英语课」），中文课那条链路一个字节都不动——只有走英语课入口才用翻译，平时默认不用。

三条红线：

1. **翻译只翻语言，不许改事实。** 不增、不删、不合并句子、不润色。原文永远是主语，译文是叠加物。
2. **原文必须完整保留。** `transcript` 存 ASR 原文，翻译单独存；任何时候删掉译文，笔记还能看。
3. **不支持的语言不许假装支持。** 硅基流动的识别接口**没有 language 参数**（已核对：只有 `file` 和 `model`），语言只能靠模型自己判断。所以"支持哪些语言"必须按**ASR 模型的实际能力**分层写清楚，并且真录音实测过再写进界面，不能列一堆语言让用户试。

### 当前代码现状（已核实，不要重新猜）

**两个可选识别模型**（`lib/config.dart:32-44`）：

| `FunAudioLLM/SenseVoiceSmall` | 默认，免费；官方支持中/粤/英/日/韩（以模型卡为准，需实测） |

**纠错是中文专用的**：`lib/services/transcript_corrector.dart` 与 `lib/agent/correction_agent.dart` 都是 A/B/C 三档 + 「同音字 / 拼音 / 平翘舌 / 专业术语」的规则，提示词里写死了「把听错的词还原成老师实际讲的内容」——在外语课里这句话会诱导模型改写甚至翻译。

**术语表**（`terminology_service.dart:80`）：`prepare(courseName, topic, material, knownTerms)`，提示词全中文，产出中文术语 + 常见误听形式。

**总结**（`ai_service.dart`）：`summarize(transcript, {level, courseName, template})`，九段式提示词全中文；`StudySummary.detailMarkdown` 是唯一的正文，没有第二语言版本。分块阈值 `chunkChars = 8000`（按中文估的）。

**笔记表**：`dbVersion = 9`，`notes` 有 `transcript / summary_json / terminology_json / course / template_id / textbook_id / chapter_no / chapter_title / section_no / section_title`，**没有语言字段，也没有译文列**。

**检索**（`search_index.dart`）：中文 bigram + 英文整词小写 + 前缀匹配，英文已经能搜；但没有"译文"这一路。

**设置页**：有 ASR 模型选择、播放档位、技能开关；没有语言相关设置。

### 硬约束

1. **外语课上不许让纠错改语言。** 纠错只允许做「拼写纠正、专名大小写、明显同音误听」，**禁止把外语词改成中文、禁止意译、禁止合并句子**。做不到就标待确认，别改。
2. **翻译必须逐句对照，行数必须能校验。** 整段翻译一定会合并句子，对照就废了。要求「一句一行、带行号」，程序校验行数与输入句数一致；不一致就丢弃重译一次，仍不一致则降级为整段翻译并标「无法逐句对照」。
3. **本版只做英语，其他语言不出现。** 英语识别走 SenseVoiceSmall（官方支持英语，但课堂场景要先实测）；日语 / 韩语 / 俄语**不允许出现在任何界面里**，也不做切句与纠错适配。等英语课跑顺了再按同一套结构扩。
4. **中文课行为必须零变化。** 所有新增逻辑默认 `language = zh` 走原路径；改完要能证明「中文课的提示词与今天逐字一致」。
5. 不引入新的第三方服务：翻译走现有 DeepSeek 通道（纯文本），不加机器翻译 API；ASR 换模型仍走硅基流动同一个接口。
6. 分阶段交付，每阶段 `flutter analyze` 零告警 + 全量测试 + 打包 APK + git 提交。

#### 〇、语言支持矩阵（先定这个，再谈功能）

| 语言 | SenseVoiceSmall | Whisper 类多语种模型 | 翻译（DeepSeek） | 结论 |
|---|---|---|---|---|
| 中文 `zh` | ✅ | ✅ | — | 现有链路 |
| 英语 `en` | ✅ | ✅ | ✅ | 可用 |
| 日语 `ja` | ✅ | ✅ | ✅ | 可用（切句要单独处理） |
| 韩语 `ko` | ✅ | ✅ | ✅ | 可用 |
| 粤语 `yue` | ✅ | ✅ | ✅ | 可用 |
| 俄语 `ru` | ❌ | ✅ | ✅ | **必须换 ASR 模型** |
| 法语 / 德语 / 西语 | ❌ | ✅ | ✅ | 同上 |

**俄语课怎么办**（这是最容易被忽略的一格）：

- 转写：`SenseVoiceSmall` 官方不支持俄语。用它录俄语课不是"识别不准"，是**根本不在词表里**——出来的会是乱码或错认成英文。
- 唯一正路：换 Whisper 类多语种模型（如 `openai/whisper-large-v3`，支持约 99 种语言，含俄语）。接口是 OpenAI 兼容的 `/audio/transcriptions`，**代码上只需要把模型名做成可配置**，上传逻辑（60 秒切片、重传、前台服务）一行都不用改。
- 前提：先在硅基流动控制台「模型广场」确认该模型在售、单价、单文件限制。本机网络到 `api.siliconflow.cn` 不通，查不了，这一步得你自己看一眼。
- 兜底：用别的工具把音频转成俄语文本，粘进录音页输入框——Agent 看到已有转写稿就不会再调 ASR，后面的翻译、总结、Wiki 全部照常。
- 翻译端没有语言限制：DeepSeek 俄→中没问题；切句器要加西里尔字母规则（`.` `!` `?`，注意俄语缩写与书名号 «»）。

**所以「多语言」得拆成两层验收**：① ASR 能选多语种模型（能力矩阵跟着模型走）；② 翻译/总结按 `language` 适配。两者互不阻塞。

**本版范围（已拍板）：只做英语。** 上面这张矩阵只是用来解释「为什么不是所有语言都能用」，日语 / 韩语 / 俄语**不进入本版界面**，也不做切句和纠错适配。等英语课跑顺了再按同一套结构扩语言。

#### 三、转写与纠错（英语）

| 语言 | 纠错策略 |
|---|---|
| 中文 `zh` | 完全保持现状（A/B/C 三档、同音字规则），代码路径不动 |
| 英语 `en` | 只做三类：拼写错误、专名大小写、明显同音误听；**禁止改语言、禁止意译、禁止合并句子**；B 类一律只标待确认 |

实现上不要复制一份提示词了事——把「能否修改」写死在提示词里，并加一条**可执行护栏**：改后的词必须与原文同字符集（拉丁 → 拉丁），跨语言改写直接丢弃并记日志。

术语表（已拍板：英文术语 + 中文释义）：
- `term` 用英文原文（如 `pinnately compound leaf`），`definition` 用中文
- `knownTerms` 传「英文（中文）」成对形式，让纠错知道标准写法
- 误听形式按英文的形近/音近生成，不要套拼音规则
- 界面统一格式：`pinnately compound leaf（羽状复叶）`

#### 四、翻译模块（逐句上下 + 自动重翻）

**只对 `language == 'en'` 的笔记调用翻译。** 中文笔记一条翻译请求都不能发——这一点要用测试锁住，不能靠"记得别调"。

新增 `services/translation_service.dart`：

```dart
Future<TranslationResult> translate({
  required String text,
  required String sourceLang,   // 本版固定 'en'
  String targetLang = 'zh',
});
```

**流程**：

1. **切句**（纯 Dart，可单测）：英语按 `. ! ?` 切，保护 `Mr.` `Dr.` `Prof.` `e.g.` `i.e.` `etc.` `Fig.` `vs.` 等缩写；引号内的句号不断开；`...` 不算句末
2. **逐句翻译**，输出 JSON：

```json
{"pairs":[{"i":1,"src":"...","dst":"..."},{"i":2,"src":"...","dst":"..."}]}
```

3. **校验**：`pairs.length == 句子数`，且每句 `src` 归一化后能在原文对应位置找到（顺序 + 内容双校验）。不通过 → 重试一次；再不过 → 整段翻译 + 标「无法逐句对照」。
4. **存储**：`notes.translation_json`，结构里带 `sourceLang / targetLang / createdAt / mode(per-sentence|whole) / pairs`。
5. **失败语义**：翻译失败不改原文、不阻塞录音；保留旧译文并标「翻译失败，点此重试」。

**详情页 UI（已拍板：逐句上下）**：
- 「对照」视图：原文一行、译文紧跟一行，句子可点回原文对应位置回听
- 默认开启（英语课笔记），不是藏在开关里
- 译文可编辑（本地），改完标 `edited`；编辑不会触发重翻，避免"边改边翻"打架

**自动重翻（已拍板）**：
- 原文被改（手动编辑、质量校准、重新转写）→ 防抖 2 秒后**自动重新翻译**
- 翻译中显示轻量进度条，不锁编辑区；失败保留旧译文并给重试入口
- 同一段落短时间反复改，只发最后一次（防抖 + 内容 hash 去重）
- 成本提示：设置页写明「英语课每节课会多一次翻译调用，约 +0.1 元」

#### 五、总结（已拍板：统一中文 + 术语带中文释义）

只做一种：**中文总结**。不做原文语言总结、不做双语总结——外语课的学生最终还是要用中文理解和复习，多一种模式只是多一套要维护的提示词。

- 术语第一次出现的格式：`cell wall（细胞壁）`（英文在前、中文在后）
- 提示词明确告知「输入是英语课堂转写，可能夹中文解释」
- 夹中文解释时如实保留「老师说：…」，不要翻译成英文
- 硬约束：**总结里不许出现原文没有的内容**
- 实现：`buildPromptForLevel` / `buildPrompt` 增加可选 `language` 参数，默认 `zh` 走原字符串（中文课逐字不变）

#### 六、检索与 Wiki

- **检索**：`IndexDoc` 加 `translation` 字段（权重 1，与原文同级或略低），译文也进 bigram/整词索引——学生用中文关键词也能搜到外语课的笔记。
- **Wiki**：`term` 存原文（`cell wall`），`definition` 存中文；唯一键仍是 `course + term`。外语课与中文课的同名词条不互相干扰（课程不同）。
- **RAG**：回答带出处；跨语言回答时标注「原文为英文，以下为译文」。

### 技术判断与风险

1. **SenseVoiceSmall 的英语识别是这套方案的地基，必须先实测。** 它官方支持英语，但课堂场景（口音、远场、夹中文解释）没验证过。**先拍一段真实英语课 5 分钟**跑转写，错词率可接受才继续；不行就先解决 ASR（换 Whisper 类模型），别急着做翻译。
2. **切句质量决定对照表能不能用。** 英文缩写断句（`Mr. Smith`、`Fig. 3`、`e.g.`）、引号内句号、省略号，都要单独处理；切句器必须是纯函数并且有测试，别藏在提示词里。
3. **翻译的忠实度靠结构约束，不靠"请忠实翻译"。** 一句一行 + 行数校验 + src 回查，是唯一能自动发现的编造方式。
4. **纠错在英语下更危险**：模型很容易"顺手把整句改写得更通顺"或翻译成中文。护栏要可执行：字符集、原文可定位、改动跨度。
5. **自动重翻是个花钱的按钮。** 用户每改一次原文都会触发翻译；防抖 + 内容 hash 去重必须做，否则一遍校对能烧掉好几节课的钱。翻译一节课约 **+0.08–0.12 元**，写进设置页说明。
6. **数据迁移**：v10 加 `language` / `translation_json` 两列，可重入；老笔记默认 `zh`，不迁移数据。
7. **中文课回归**：英语课走独立入口，中文链路一行不改；测试里加「中文课提示词与 v1.1.0 逐字一致」和「中文笔记不调用翻译」两条断言。

- 术语表：英文 term + 中文 definition，`knownTerms` 双语
- 测试：英文文本不会被改成中文、中文课走旧提示词、术语格式正确
- analyze + 全量测试 + 打包

**第五阶段：总结 + 检索/Wiki + 真机实测**
- 总结只出中文，术语首次出现 `cell wall（细胞壁）`
- 译文进检索索引、Wiki 英文 term + 中文定义
- 真实英语课录音实测 5–10 分钟，把识别质量与翻译质量的结论写进文档
- analyze + 全量测试 + 打包

### 验收标准

- **中文课**：首页除了多一个「英语课」入口，其余没有变化；提示词与 v1.1.0 逐字一致；现有 376 个测试全过；**中文笔记不发起任何翻译请求**（测试断言，不靠人工检查）
- **英语课**：从独立入口进入，AppBar 写「英语课」；转写保留英文原文；对照表句数 = 切句数；总结里术语首次出现格式为 `cell wall（细胞壁）`
- **自动重翻**：编辑原文后 2 秒内自动重翻一次；连续改 5 次只发 1 次请求（防抖 + hash 去重）
- **翻译失败**：原文不动、保留旧译文并提示重试；不阻塞编辑、保存与录音
- **混说**（英文为主 + 老师中文解释）：两种语言都保留，不丢句、不崩
- **老笔记**（无 `language` 字段）按 `zh` 处理，打开不出现翻译 UI
- 英语课入口在首页可见；中文记录页没有语言选择器、没有翻译按钮

### 最后一条

每阶段做完停下等用户确认再继续。多语言涉及提示词、存储和外部模型三处改动，一次改太多很难验。

### 自检修复（v1.3.1）

| 问题 | 修法 |
|---|---|
| 翻译结果回写用了翻译开始时的旧 note，可能覆盖用户刚保存的原文 | 用当前 `_note` 回写；翻译期间原文变了就丢弃这次结果并重排 |
| 翻译进行中改原文，定时器被 `_translating` 挡掉，这次改动永远等不到译文 | 翻译结束后比较当前原文，不一致就再排一次 |
| 用「句子拼起来」和原文做相等判断，换行/空格差异被判成改过，每次保存都白翻一次 | 归一化（去空白）后比较 |
| 翻译失败后把失败文本记成「已翻译」，点开对照会显示旧译文 | 改成独立失败标记；自动不重试，主动点开仍强制重试 |
| 术语缓存键只有课程+章节，同门课的中文术语包可能喂给英语课纠错 | 键加语言前缀（`语言|课程|章节`） |
| 中文关键词命中英语课译文时，搜索结果显示的是无关的原文片段 | 原文定位失败就退到译文定位，片段标「〔译文〕」 |
| 首页两个悬浮按钮会盖住最后一张卡片 | 列表底部留 110 的空白 |

## 五、一句话

中文课的链路是"听懂老师说了什么"，外语课还得再往前一步——"这句话用中文怎么说，用原文又长什么样"。这两件事必须分开存，否则学生永远在猜哪句是老师原话。
